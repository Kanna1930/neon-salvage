Neon Salvage is a 2D neon arcade game: pilot a salvage ship through an asteroid field, grab glowing cores to build a combo multiplier, blast splitting rocks, and survive escalating waves with shield, magnet and overdrive power-ups. Keyboard and mouse, no build step, no network requests.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.
